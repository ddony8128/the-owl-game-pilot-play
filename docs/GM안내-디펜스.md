# 디펜스 딜레마 — GM 안내문 (플레이어 관점 · 규칙 포함)

몰려오는 몬스터를 함께 막되 점수는 개인이 경쟁하는 디펜스 게임입니다. 규칙·진행·플레이어 플레이 방식을 모두 담았습니다.

---

> **운영은 방(room) 단위입니다.** 한 배포 + 한 DB 가 여러 방을 동시에 호스팅합니다.
> GM이 방을 만들면 **코드(예 `A3F82`)**가 발급되고, 참가자는 그 **코드 + 닉네임**으로 입장합니다.

| 용도 | 경로 |
| --- | --- |
| **GM 방 관리**(방 생성·참가자 등록·입장) | `https://the-owl-game-pilot-play-real.vercel.app/dashboard/x9a2k7` |
| GM 진행 대시보드(방 입장 후) | `https://the-owl-game-pilot-play-real.vercel.app/dashboard/x9a2k7/defense?room=코드` |

> 진행 대시보드·결과 중계는 직접 열지 말고 **"방 관리"에서 그 방의 버튼**으로 들어가세요(방 코드가 URL에 붙습니다).

## 1. 목표
몬스터 무리를 처치하면 포인트를 얻고, 게임 종료 시 **포인트가 가장 높은 플레이어가 승리**합니다.
몬스터는 함께 잡지만 점수는 나눠 갖기에 "딜레마": 같이 쳐야 잡히는데 점수는 경쟁입니다.

## 2. 진행 구조
- **튜토리얼 2라운드 + 본게임 12라운드** (플레이어 화면엔 본게임이 1~12라운드).
- 각 라운드: **① 행동 단계(5분) → ② 전투 처리(GM이 라운드 넘김) → ③ 라운드 종료**.
- 누가 무엇을 했는지/어느 몬스터에 카드를 냈는지는 **서로 비공개**.

## 3. 카드 / 행동
각 플레이어는 숫자 카드 **1·2·3·4**(전부 활성)로 시작. 라운드마다 **하나만** 선택:
- **전투**: 대기열 몬스터 1마리 선택 + 활성 카드 1장 제출(제출 카드는 비활성). 같은 몬스터를 여럿이 치면 숫자 합산.
- **휴식**: 비활성 카드 **최대 3장** 재활성화.
- **훈련**: 활성 카드 1장 비활성화 + 카드 1장의 숫자 **영구 +1**.

- 깎다 만 HP는 다음 라운드로 누적. 몬스터 도감 탭에서 미리 확인 가능.

### 인원별 세팅 (7~12명)

- **대기열**은 인원에 따라 자동으로 정해집니다: **7~9명 4칸 / 10~12명 5칸**.

## 5. 점수 / 라운드 종료
- **처치 성공**(제출 숫자 합 ≥ 현재 HP): 포인트를 **공격 인원수로 균등 분배**(내림, 나머지 소멸). 예: 4점을 3명이 잡으면 각 1점.
- **실패**: HP만 깎이고 몬스터는 잔류(점수 없음).
- **라운드 종료 시**: 살아남은 몬스터 잔여시간 -1 → 0이면 도망. **도망친 몬스터가 있으면 전원 가장 큰 활성 카드 1장이 비활성화**(놓침 페널티). 빈 대기열은 새 몬스터로 채움.

## 6. 승패
- 종료: 몬스터 전부 처치/도망 또는 12라운드 종료(GM이 라운드를 끝까지 진행해 마무리).
- 순위: **포인트 → 동점 시 전투에 쓴 누적 숫자(데미지) 큰 쪽 → 그래도 동점이면 공동.**
- 4·8라운드 종료 후 중간 점수 공개.

## 7. GM 진행 순서
1. **방 관리(`/dashboard/x9a2k7`)** 에서 **[+ 디펜스 방]** → 코드(예 `A3F82`) 발급.
2. 그 방의 **[참가자]** 로 이번 팀 닉네임을 모두 등록(등록된 사람만 입장 가능).
3. **[대시보드 입장] → [몬스터 수 조절] → [인원 기준 자동 세팅] → [저장]** (게임 시작 전). 등록 인원에 맞춰 조합(총 = 인원 × 3)과 대기열(7~9명 4칸 / 10~12명 5칸)이 자동 세팅됩니다. 대기열 칸 수는 **첫 라운드 진입 시점의 등록 인원**으로 정해지니, **모두 등록·저장을 마친 뒤 시작**하세요.
4. 참가자에게 **방 코드**를 안내 → 참가자는 `https://the-owl-game-pilot-play-real.vercel.app/` 에서 **방 코드 + 닉네임**을 입력하면 **곧바로 디펜스 화면으로 진입**합니다.
   - GM이 "준비 상태"로 만들 필요는 없습니다. **방을 만들고 닉네임을 등록하면 바로 입장 가능**하고, 입장하면 0라운드(대기)로 보입니다.
5. **카운트다운(5분) 시작/일시정지**, 라운드 진행, **점수 ±** 수동 보정(예외 처리용). 각 라운드: 플레이어 행동(5분) → **다음 라운드**로 전투 처리 → 결과 확인.
6. **결과 중계([결과 페이지 ↗] = `/defense-board?room=코드`)** 를 빔에 송출.
7. **다음 팀**은 방 관리에서 **새 방을 만들면 됩니다.** 끝난 방은 **[종료]** 표시만 해두면 됩니다(이전 기록 보존).

## 8. 플레이어 안내 (입장 시 설명용)
- "화면 탭: 정보 / 행동 / 규칙 / 몬스터 도감 / 로그. 행동은 비공개니 화면을 가려도 됩니다."
- "라운드마다 전투·휴식·훈련 중 **하나만** 고릅니다. 전투는 몬스터+카드 선택 후 확정."
- "여럿이 같은 몬스터를 쳐야 큰 놈이 잡히고, 점수는 친 사람끼리 나눕니다."
- "몬스터를 놓치면(도망) 모두의 가장 큰 카드가 한 장 잠깁니다. 5분 안에 행동하세요."
