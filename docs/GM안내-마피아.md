# 자본주의 마피아 — GM 안내문 (플레이어 관점 · 규칙 포함)

직업을 경매로 얻고, 주식과 능력으로 자산을 불리는 경제 심리 게임입니다. 규칙·진행·플레이어 플레이 방식을 모두 담았습니다.

---

> **운영은 방(room) 단위입니다.** 한 배포 + 한 DB 가 여러 방을 동시에 호스팅합니다.
> GM이 방을 만들면 **코드(예 `A3F82`)**가 발급되고, 참가자는 그 **코드 + 닉네임**으로 입장합니다.

| 용도 | 경로 |
| --- | --- |
| **GM 방 관리**(방 생성·참가자 등록·입장) | `https://the-owl-game-pilot-play-real.vercel.app/dashboard/x9a2k7` |
| GM 진행 대시보드(방 입장 후) | `https://the-owl-game-pilot-play-real.vercel.app/dashboard/x9a2k7/mafia?room=코드` |

> 진행 대시보드·결과 중계는 직접 열지 말고 **"방 관리"에서 그 방의 버튼**으로 들어가세요(방 코드가 URL에 붙습니다).

## 1. 목표
여러 라운드 동안 **자산(현금 + 보유 주식 평가액)**을 가장 많이 모으는 것이 목표입니다.
게임 종료 시 **총자산이 가장 높은 사람이 1등**(동점 시 현금이 많은 쪽).

## 2. 라운드 진행 (5단계 페이즈)
GM이 페이즈를 순서대로 넘기며 진행합니다.

| 페이즈 | 플레이어가 하는 일 |
| --- | --- |
| **라운드 준비(prepare)** | 정보·주가 확인 |
| **직업 경매(auction)** | 원하는 직업에 현금을 베팅. 최고가가 그 직업 획득(미베팅·실패자는 **월급쟁이**) |
| **주식 거래(trade)** | 종목을 사고팖 |
| **주가 변동(apply)** | 직업 능력·조작이 일괄 반영되어 주가가 움직이고, 능력 결과가 정산됨 |
| **투표(vote)** | 대상에게 표를 행사(표 가격만큼 현금 소모, 잔액 검증). 표 가격은 **시장** 능력으로 결정 |

→ 라운드 종료 후 다음 라운드 반복.

## 3. 주식 · 주가 변동 규칙
- 종목: **부엉교육 · 번쩍전기 · 국채 · 이상교통** (시작가 5원 동일).
- **국채는 주가 조작 대상에서 제외**(안전 자산).
- **주가 변동 페이즈에 다음이 합산 반영**(최종 주가는 **최소 1원**):
  - 자연 변동: 이번 라운드 **최다 매수 종목 +1**, **최다 매도 종목 -1** (동률이면 해당 종목 모두).
  - 상승 주가조작: **+1** (그 종목이 최다 매도 종목이면 **+2**).
  - 하락 주가조작: **-2** (그 종목이 최다 매수 종목이면 **-3**).

## 4. 직업 (경매로 획득)

**마피아 진영** (정체가 숨겨짐, **월급 없음** — 능력으로 벌이):
- **상승 주가조작가**: 지정 종목(국채 제외) 주가 **+1** (최다 매도 종목이면 **+2**).
- **하락 주가조작가**: 지정 종목 주가 **-2** (최다 매수 종목이면 **-3**).
- **강도**: 지정한 2명에게서 각자 **이번 라운드 수익의 25%(버림)**를 강탈. **단, 시장은 면역**(공격을 막고 강도의 정체를 알게 됨).

**시민 진영**:
- **경찰** (월급 **5원**): 지정한 두 명이 **마피아인지 여부**를 조사해 결과를 받음.
- **세무조사원** (월급 **5원**): 지정 대상의 **보유 주식·이번 라운드 거래 내역**을 확인.
- **증권사 직원(브로커)**: 지정 종목의 **이번 라운드 총 거래금액의 10%(버림)**를 현금으로 획득.
- **사장(CEO)** (월급 **10원**): 자신 제외 1명에게 **5원 지급**(받은 대상은 CEO의 정체를 알게 됨).
- **시장(Mayor)** (월급 **5원**): 이번 라운드 **투표 표 가격(1/2/3원)**을 결정. (강도 면역)
- **월급쟁이**: 능력 없음, 매 라운드 **월급 3원**. (경매 미참여·낙찰 실패자는 자동 월급쟁이)

> 능력은 "능력사용" 탭에서 대상/종목을 지정 → 주가 변동 페이즈에 시스템이 일괄 처리, "능력결과" 탭으로 결과를 돌려줍니다.

## 5. 플레이어 화면 탭 (페이즈에 따라 동적)
- 항상: **정보**(현금·총자산·보유주식·직업), **규칙**, **주가**
- 경매 페이즈: **경매** 탭
- 거래/능력 페이즈: **거래**, **능력사용** 탭
- 능력/투표 페이즈: **능력결과** 탭
- 투표 페이즈: **투표** 탭

## 6. GM 진행 순서
1. **방 관리(`/dashboard/x9a2k7`)** 에서 **[+ 마피아 방]** → 코드(예 `A3F82`) 발급.
2. 그 방의 **[참가자]** 로 이번 팀 닉네임을 모두 등록(등록된 사람만 입장 가능).
3. 참가자에게 **방 코드**를 안내 → 참가자는 `https://the-owl-game-pilot-play-real.vercel.app/` 에서 **방 코드 + 닉네임**을 입력하면 **곧바로 마피아 화면으로 진입**합니다.
   - GM이 "준비 상태"로 만들 필요는 없습니다. **방을 만들고 닉네임을 등록하면 바로 입장 가능**하고, 입장하면 초기 상태(준비/0라운드)로 대기합니다.
4. 그 방의 **[대시보드 입장]** → 마피아 대시보드에서 **라운드 선택** 후 페이즈를 **준비 → 경매 → 거래 → 주가변동 → 투표** 순으로 넘김. 일부 전환에서 **타이머가 자동으로 리셋**되고, 플레이어 화면은 자동으로 갱신됩니다.
5. **자산 현황 / 주가 / 라운드별 요약 / 공개 로그**로 모니터링. **결과 중계([결과 페이지 ↗] = `/mafia-board?room=코드`)**: 총자산 순위 + 종료 시 **마피아 공개** 토글.
6. **다음 팀**은 방 관리에서 **새 방을 만들면 됩니다.** 끝난 방은 **[종료]** 표시만 해두면 됩니다(이전 기록 보존).
