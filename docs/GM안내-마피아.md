# 자본주의 마피아 — GM 안내문 (플레이어 관점 · 규칙 포함)

## 1. 목표
여러 라운드 동안 **자산(현금 + 보유 주식 평가액)**을 가장 많이 모으는 것이 목표입니다.
게임 종료 시 **총자산이 가장 높은 사람이 1등**(동점 시 현금이 많은 쪽).

## 2. 라운드 진행 (5단계 페이즈)
GM이 페이즈를 순서대로 넘기며 진행합니다.

| 페이즈 | 플레이어가 하는 일 |
| --- | --- |
| **라운드 준비(prepare)** | 정보·주가 확인 |
| **직업 경매(auction)** | 원하는 직업에 현금을 베팅. 최고가가 그 직업 획득(미베팅·실패자는 **월급쟁이**) |
| **주식 거래(trade)** | 종목을 사고팖 |
| **주가 변동(apply)** | 직업 능력·조작이 일괄 반영되어 주가가 움직이고, 능력 결과가 정산됨 |
| **투표(vote)** | 대상에게 표를 행사(표 가격만큼 현금 소모, 잔액 검증). 표 가격은 **시장** 능력으로 결정 |

→ 라운드 종료 후 다음 라운드 반복.

## 3. 주식 · 주가 변동 규칙
- 종목: **부엉교육 · 번쩍전기 · 국채 · 이상교통** (시작가 5원 동일).
- **국채는 주가 조작 대상에서 제외**(안전 자산).
- **주가 변동 페이즈에 다음이 합산 반영**(최종 주가는 **최소 1원**):
  - 자연 변동: 이번 라운드 **최다 매수 종목 +1**, **최다 매도 종목 -1** (동률이면 해당 종목 모두).
  - 상승 주가조작: **+1** (그 종목이 최다 매도 종목이면 **+2**).
  - 하락 주가조작: **-2** (그 종목이 최다 매수 종목이면 **-3**).

## 4. 직업 (경매로 획득)

**마피아 진영** (정체가 숨겨짐, **월급 없음** — 능력으로 벌이):
- **상승 주가조작가**: 지정 종목(국채 제외) 주가 **+1** (최다 매도 종목이면 **+2**).
- **하락 주가조작가**: 지정 종목 주가 **-2** (최다 매수 종목이면 **-3**).
- **강도**: 지정한 2명에게서 각자 **이번 라운드 수익의 25%(버림)**를 강탈. **단, 시장은 면역**(공격을 막고 강도의 정체를 알게 됨).

**시민 진영**:
- **경찰** (월급 **5원**): 지정한 두 명이 **마피아인지 여부**를 조사해 결과를 받음.
- **세무조사원** (월급 **5원**): 지정 대상의 **보유 주식·이번 라운드 거래 내역**을 확인.
- **증권사 직원(브로커)**: 지정 종목의 **이번 라운드 총 거래금액의 10%(버림)**를 현금으로 획득.
- **사장(CEO)** (월급 **10원**): 자신 제외 1명에게 **5원 지급**(받은 대상은 CEO의 정체를 알게 됨).
- **시장(Mayor)** (월급 **5원**): 이번 라운드 **투표 표 가격(1/2/3원)**을 결정. (강도 면역)
- **월급쟁이**: 능력 없음, 매 라운드 **월급 3원**. (경매 미참여·낙찰 실패자는 자동 월급쟁이)

> 능력은 "능력사용" 탭에서 대상/종목을 지정 → 주가 변동 페이즈에 시스템이 일괄 처리, "능력결과" 탭으로 결과를 돌려줍니다.

## 5. 플레이어 화면 탭 (페이즈에 따라 동적)
- 항상: **정보**(현금·총자산·보유주식·직업), **규칙**, **주가**
- 경매 페이즈: **경매** 탭
- 거래/능력 페이즈: **거래**, **능력사용** 탭
- 능력/투표 페이즈: **능력결과** 탭
- 투표 페이즈: **투표** 탭

## 6. GM 진행 순서
1. 메인 대시보드: **참가자 등록** → `active_game` 을 **mafia_tutorial**(튜토리얼) 또는 **mafia**(본게임).
2. 마피아 대시보드에서 **라운드 선택** 후 페이즈를 **준비 → 경매 → 거래 → 주가변동 → 투표** 순으로 넘김.
   - 일부 전환에서 **타이머 자동 리셋**. 화면은 자동 갱신(폴링).
3. **자산 현황 / 주가 / 라운드별 요약 / 공개 로그**로 모니터링. 공개 멘트는 "라운드 로그"로 송출.
4. **결과 중계(`/mafia-board`)**: 총자산 순위 리더보드 + 종료 시 **마피아 공개** 토글.
5. 종료 후 세션 초기화(다음 팀 준비).
